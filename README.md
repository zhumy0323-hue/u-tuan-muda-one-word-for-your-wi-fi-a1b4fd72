## What this entry is

One word describing my Wi-Fi: **Schrödinger**.

## Why it's good

It's funny and accurate at the same time. My Wi-Fi is simultaneously
connected and not connected — full bars right up until the moment
something actually needs it, when it collapses into nothing. You only
find out which state it was in by trying to load a page, exactly like
opening the box. The joke lands for anyone who has ever stared at a
spinner on full signal. One word, no explanation needed, and it doubles
as a network name the sponsor could actually use.

## How to run

```sh
python3 main.py
```

This writes the entry word to `/output/entry.txt` (UTF-8, one line, no
trailing newline). Standard library only, no network, no randomness —
running it twice produces byte-identical output.
